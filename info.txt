Flat files sharing - API Specification
Flat files sharing m2m solution consists of two steps:
• Authentication
• Get Files
Authentication
Parameter Value
In Preprod: https://explorajourneys-b2b.oktapreview.com/api/v1/authn
URL
In Production: https://idpb2b.explorajourneys.com/api/v1/authn
Method POST
Header Content-Type: application/json
{
"username": "user@test.com",
Body
"password": "password#123"
}
Username corresponds to the email through which Explora Journeys provides you access to the application.
Password is set directly by you upon receiving a welcome email from OKTA after the access to the application is granted.
NOTE 1
Preprod and Production are two different instances and therefore require two different accounts. Please make sure to activate both accounts upon
receiving the dedicated Okta email (Username may be the same in both environments).
Also, please note we only give Preprod access to Partners integrating our full booking flow API. Otherwise, for flat files only, production access is enough.
NOTE 2
If Postman is used make sure to have the following hidden headers flagged:
Content-Lenght: <calculated when request is sent>
Host: <calculated when request is sent>

Get Files
This API provides the list of available files in a directory tree structure. The s3SignedUrl can be
used to download the file. The link expires in 60 seconds, after that the APIs need to invoked
again to get the updated URLs.
Parameter Value
In Preprod: https://preprod.techpartner.explorajourneys.com/
URL
In Production: https://techpartner.explorajourneys.com/
Method GET
End Point /ota/file/operations/system/
Parameters None
Header Authorization: <Session Token>
The session token is retrieved using the authentication call (highlighted on slide 3).
Note that this token is valid only for a single call to the get files API. If the source system needs to call the get files API again, the session token needs to
be re-generated.
